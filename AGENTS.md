# Repository Structure

This is a directory-per-topic learning path for building backend APIs with Bun, Elysia, and TypeScript.

## Structure

```
README.md                              — Navigation table and learning objectives
00-foundations/                        — Programming concepts and JS context
  01-what-is-programming.md
  02-paradigms.md
  03-sequential-decision-iteration.md
  04-compiler-vs-interpreter.md
  05-what-is-javascript.md
  06-why-js-ts-why-not-x.md
01-first-code/                         — Write your first programs
  01-setup.md
  02-variables-and-types.md
  03-control-flow.md
  04-functions.md
  05-data-structures.md
02-core-language/                      — Async, modules, TypeScript
  01-async-programming.md
  02-modules.md
  03-typescript-basics.md
  04-type-inference-and-narrowing.md
  05-the-event-loop.md
03-backend-fundamentals/               — HTTP, REST, API, database, validation
  01-http-and-web-servers.md
  02-rest-api-design.md
  03-your-first-api.md
  04-database-access.md
  05-validation.md
04-production/                         — Testing, logging, config, deployment
  01-testing.md
  02-logging-and-monitoring.md
  03-configuration.md
  04-deployment.md
05-workshop/                           — Full project
  README.md
```

## Conventions

- Each file is 200-500 words. Self-contained.
- Code examples run with `bun run <file>`.
- Files are numbered for reading order.
- ``, ``, `` badges indicate difficulty.
